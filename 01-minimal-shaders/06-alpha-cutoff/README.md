# Lesson: Alpha Cutoff

Part of the **01-minimal-shaders** module in the Panda3D GLSL Shader Laboratory.

## 📖 Overview

This lesson isolates and demonstrates **Alpha Cutoff**. It illustrates foundational programmable GPU pipeline mechanics in Panda3D using GLSL, applying custom shaders directly onto the `models/smiley` model.

## 🔺 Vertex Shader

File: `Minimal-Alpha-Cutoff-Shader.vert`

```glsl
#version 150
/* 
   Specifies the GLSL language version used by this vertex shader.

   "#version 150" corresponds to GLSL 1.50,
   introduced with OpenGL 3.2.

   This version:
     - uses modern "in" and "out" qualifiers
     - removes deprecated fixed-function pipeline features
     - is compatible with Panda3D’s GLSL system
*/


in vec4 p3d_Vertex;
/*
   Declares a vertex position input attribute.

   "p3d_Vertex" is a built-in Panda3D attribute
   containing the vertex position in model-local space.

   Type: vec4
     x, y, z → spatial coordinates
     w       → usually 1.0 for positions
*/


in vec2 p3d_MultiTexCoord0;
/*
   Declares a vertex texture coordinate input attribute.

   "p3d_MultiTexCoord0" is a built-in Panda3D attribute
   containing the first set of UV coordinates for the vertex.

   Type: vec2 (u, v):
     u → horizontal texture coordinate
     v → vertical texture coordinate
*/


out vec2 v_uv;
/*
   Declares an output variable to pass data to the fragment shader.

   "v_uv":
     - carries the texture coordinates from vertex shader → fragment shader
     - is automatically interpolated across each triangle
     - allows the fragment shader to sample the texture accurately
*/


uniform mat4 p3d_ModelViewProjectionMatrix;
/*
   Declares a uniform transformation matrix.

   "p3d_ModelViewProjectionMatrix" combines:
     - Model transformation
     - View (camera) transformation
     - Projection (perspective) transformation

   This converts model-space positions into clip-space coordinates.
*/


void main() {
/*
   Entry point of the vertex shader.

   This function runs once per vertex
   processed by the GPU.

   Responsibilities of this vertex shader:
     - pass UV coordinates to the fragment shader
     - compute the final clip-space position
*/


    v_uv = p3d_MultiTexCoord0;
    /*
       Passes the texture coordinates to the fragment shader.

       Each fragment receives its own interpolated UVs,
       allowing proper texture sampling.
    */


    gl_Position = p3d_ModelViewProjectionMatrix * p3d_Vertex;
    /*
       Computes the final vertex position in clip space.

       "gl_Position" is required by GLSL.
       The MVP matrix transforms model-space coordinates
       to clip space for rasterization.
    */
}


/*
   After the vertex shader completes:

     - v_uv is interpolated across triangles
     - vertices are assembled into primitives
     - triangles are rasterized
     - the fragment shader runs per fragment

   This vertex shader only passes UVs and transforms positions.
*/
```

## 🎨 Fragment Shader

File: `Minimal-Alpha-Cutoff-Shader.frag`

```glsl
#version 150
/* 
   Specifies the GLSL version used by this fragment shader.

   GLSL 1.50:
     - requires explicit fragment outputs
     - disallows deprecated gl_FragColor
     - must match the vertex shader version
*/


in vec2 v_uv;
/*
   Declares an input variable from the vertex shader.

   "v_uv":
     - contains interpolated texture coordinates for this fragment
     - allows sampling the correct color from the texture
*/


out vec4 fragColor;
/*
   Declares the output color of the fragment shader.

   "fragColor":
     - represents the final RGBA color
     - is written to the framebuffer

   Components:
     R → red
     G → green
     B → blue
     A → alpha (opacity)
*/


uniform sampler2D tex;
/*
   Declares a 2D texture sampler.

   "sampler2D":
     - represents a texture bound by the application
     - allows lookup of color values using UV coordinates

   Panda3D binds the actual texture object before drawing.
*/


uniform float cutoff;
/*
   Declares a uniform threshold for alpha testing.

   "cutoff":
     - is supplied by the application
     - determines the minimum alpha value required for a fragment to be visible
     - fragments with alpha below cutoff will be discarded
*/


void main() {
/*
   Entry point of the fragment shader.

   This function runs once per fragment generated by rasterization.

   Responsibilities:
     - sample the texture
     - optionally discard fragments based on alpha
     - output the final color
*/


    vec4 color = texture(tex, v_uv);
    /*
       Samples the texture at the given UV coordinates.

       Returns a vec4:
         R, G, B → color channels
         A       → alpha channel
    */


    if (color.a < cutoff)
        discard;
    /*
       Performs alpha testing.

       If the sampled alpha is below the cutoff:
         - discard the fragment
         - the fragment is not written to the framebuffer
         - allows transparency and masking effects
    */


    fragColor = color;
    /*
       Assigns the final color to the fragment.

       The output color includes:
         - RGB from the sampled texture
         - Alpha from the sampled texture

       Fragments that passed the cutoff will appear normally.
    */
}


/*
   End of the fragment shader.

   Combined effect of both shaders:

     - geometry passes UV coordinates to the fragment shader
     - the fragment shader samples the texture
     - fragments with low alpha are discarded
     - the object is rendered with alpha-masked transparency
*/
```
